产品简介

FluxTranslate 是一款简洁、高效的桌面翻译工具，支持多种语言互译，并提供本地历史记录管理功能。

技术栈

  • Electron - 跨平台桌面应用框架
  • Node.js - 后端服务
  • MyMemory API - 翻译服务提供商
